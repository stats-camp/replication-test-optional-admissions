# Replication: Examining Key Impacts of the Test-Optional Movement for Early Adopters

Brianna Felegi, *AEA Papers and Proceedings* 115 (2025), 682–688.
[Paper](https://www.aeaweb.org/articles?id=10.1257/pandp.20251057) ·
[Official deposit, package 226241 V1](https://doi.org/10.3886/E226241V1)

This repository prepares the official deposit for [stats.camp](https://stats.camp).
The datasets, spreadsheet files, and reference tables retain their original
bytes and relative paths. [README.txt](README.txt) adapts the author's package
documentation for stats.camp; the original PDF is maintained separately. Two do-files
carry local modifications, documented under
[Local modifications](#local-modifications): the author's absolute Mac path was
replaced by the repository root, and the analysis do-file also runs on its own
(as stats.camp opens it), falling back to the deposited cleaned panel. No
analysis command or dataset was changed.

**Open the analysis in stats.camp:**
[aeapp-2025-1057-analysis.do](https://stats.camp/app?open=https%3A%2F%2Fgithub.com%2Fstats-camp%2Freplication-test-optional-admissions.git&file=do%2Faeapp-2025-1057-analysis.do)

The deposit contains 116,308,969 bytes of files (116.31 MB in decimal units).
The largest file is the cleaned analysis dataset, 4,526,939 bytes. Mac resource-fork
files (`._*`) are also preserved. The author's documentation specifies less than ten minutes for analysis. The preparation pipeline was executed in a scratch copy
on 2026-10-14; it is not run in this checkout.

## What runs now

**The analysis runs end to end in stats.camp and reproduces the deposited
point estimates.** `csdid` (panel and repeated cross sections, every `drdid`
method), `csdid_stats ... wboot estore()`, `estadd scalar`, `esttab using ...
.csv` with `cells()`, `missings`, `translate` and `cd` are implemented. On
2026-10-14 and 2026-10-15 the analysis was checked against a reference
implementation (csdid 1.81, drdid 1.91) using the native stats.camp engine
on scratch copies of this repository,
with `global root` set to the copy and the deposited
`clean_school_nonbalanced_final_evertreat_apr2022.dta` aliased under the name
the script requests:

| Check | Result |
| --- | --- |
| 11 ATT point estimates (Tables 1–3) | equal to the reference implementation and deposited CSV tables |
| Group-time effects and variances | equal to about 1e-7 and 1e-6 relative (the reference `logit` uses a looser stopping tolerance) |
| Wild-bootstrap standard errors | differ within bootstrap noise; the deposit sets no seed |
| RIF datasets written by `saverif()` | interoperate with the reference `csdid_stats` |
| Raw-data preparation (scratch copy) | intermediate and final panels match the reference except for string encoding and float/double storage types |

Two differences remain in the transcript: `estadd scalar` does not echo the reference
`added scalar: e(n1) = ...` lines, and the engine's `esttab` CSV output carries
the significance legend that estout prints by default (the deposited CSVs do
not). The deposited `combine_clean_data.do` has a stray `, nogen` line that stops
execution in both implementations, so the full master cannot run unchanged.
On 2026-10-19 the analysis do-file, opened on its own as the link above does,
ran in a headless browser against a local build of stats.camp without errors
and with the same 11 point estimates.

Consequences:

- Run the master or the analysis do-file from the repository root (stats.camp

  panel `clean_school_nonbalanced_final_evertreat_apr2022.dta`; after a full
  preparation it uses the rebuilt unsuffixed file, as deposited.
- The original do-files are available from the official deposit.
- The analysis runs in stats.camp (see [What runs now](#what-runs-now)); the
  master's final `translate` is implemented as well.

## Paths and deposited-file inconsistencies

The deposit set `root` to the author's Mac directory and both master and analysis
repeatedly changed to its `data/rif` directory; see
[Local modifications](#local-modifications) for the replacement.

Analysis line 9 requests `clean_school_nonbalanced_final_evertreat.dta`, while the
deposited cleaned file ends in `_apr2022.dta`. Full preparation writes the
unsuffixed name; without it the analysis now falls back to the deposited file
(see [Local modifications](#local-modifications)); earlier validation runs
aliased it in a scratch copy. Do not run the preparation or analysis in the source checkout: their
`replace` and `erase` commands overwrite deposited intermediates, RIFs, and
reference CSV tables. Use a separate writable workspace.
